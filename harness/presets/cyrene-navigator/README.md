# Default Navigator agent / 默认 Navigator Agent

`agent.cordis.yml` composes upstream plugins. `preset.yml` supplies display
metadata only. Persistence, model routes, approvals and the native host stay in
the host Profile; this preset owns no server authority.

本目录只组合上游插件。持久化、模型路由、审批与 Native Host 仍在 Profile 中，
Agent 预设不另建服务真源。读写和 Shell 操作继续受上游权限与审批控制。
